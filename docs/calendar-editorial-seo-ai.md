# Calendar editorial SEO + AI

Scop: articole de blog construite ca raspunsuri la intrebari comerciale si informationale reale, utile atat pentru Google Search, cat si pentru raspunsuri generate de AI. Briefurile de mai jos evita date, bugete si praguri neverificate. Orice informatie oficiala care trebuie confirmata inainte de redactare este marcata cu `TODO_SURSA_OFICIALA`.

## Principii editoriale

- Fiecare articol trebuie sa raspunda rapid la intrebare in primele 2-3 fraze.
- Cifrele, perioadele de depunere, pragurile SO, procentele de cofinantare, punctajele si listele de documente trebuie preluate doar din ghiduri oficiale active.
- Articolele comerciale trebuie sa duca spre verificare eligibilitate, consultanta de program sau contact.
- Articolele informationale trebuie sa includa surse oficiale, exemple de situatii si linkuri catre paginile de servicii relevante.
- Pentru local/regional, unghiul local este folosit doar unde exista legatura reala cu ADR, program regional, economie locala, sedii/beneficiari sau pagini locale existente.
