## 5. Studii de caz

Prioritate: important

Informatii necesare pentru fiecare studiu de caz:

- Domeniu / industrie.
- Judet sau regiune, daca poate fi publicata.
- Tip solicitant: SRL, PFA, fermier, institutie, ONG etc.
- Program vizat.
- Investitie dorita.
- Valoare proiect / valoare grant, doar daca este aprobata pentru publicare.
- Status: analizat, depus, contractat, implementat, respins, retras.
- Problema initiala.
- Ce a verificat FABER.
- Documente sau riscuri clarificate.
- Rezultat sau lectie invatata.
- Acord explicit pentru publicare.

Format recomandat:

```text
Titlu: Studiu de caz anonimizat - [program] pentru [tip beneficiar]
Context: 2-3 fraze
Provocare: ce bloca proiectul
Ce am verificat: eligibilitate, documente, buget, cofinantare, riscuri
Decizie: depunere / amanare / schimbare program / completare documente
Rezultat: doar daca este dovedit si aprobat pentru publicare
Lectie utila: concluzie citabila pentru alti solicitanti
```

Cum se anonimizeaza:

- Nu se publica nume client fara acord.
- Nu se publica CUI, adresa exacta, contracte, extrase financiare sau date personale.
- Se poate folosi formatul: "ferma vegetala din Nord-Est", "IMM de servicii IT din Iasi", "firma de productie din regiunea Nord-Est".
- Valorile se pot rotunji sau exprima in intervale daca acordul clientului permite.
- Rezultatele se publica doar cu dovada si aprobare.
