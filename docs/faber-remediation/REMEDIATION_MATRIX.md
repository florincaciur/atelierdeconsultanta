## Legendă

- **P0**: risc de publicare, factualitate, conformitate sau gate critic; se tratează înaintea schimbărilor dependente.
- **P1**: risc important de regresie/mentenanță/SEO; se remediază în task dedicat.
- **P2**: îmbunătățire de robustețe sau documentație, fără defect critic demonstrat imediat.
- **NEEDS_CONFIRMATION**: implementarea depinde de date sau aprobări interne care nu pot fi deduse din repo.
